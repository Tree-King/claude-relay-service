# Claude Code 版本對齊說明

本節整理近期新增的「統一 Claude Code 版本」校驗邏輯，便於管理端與客戶端理解行為並排查問題。

## 版本來源
- **服務端版本**：由後端啟動時載入，統一回報給管理介面。
- **客戶端版本**：客戶端請求頭攜帶的 `User-Agent` 或自定義標記。後端在 API Key 上保存最後一次上報的客戶端版本。

## 校驗條件
- 管理面啟用「統一 Claude Code 版本」後，後端會在請求入口檢查：
  1. API Key 綁定的客戶端版本必須存在。
  2. 客戶端上報版本需與服務端統一版本一致。
- 任一條件不滿足時，請求會被拒絕並記錄日誌，避免不一致的客戶端繼續連線。

## 呈現位置
- 管理端「API Keys」列表同時展示**客戶端**與**服務端**版本，方便快速比對。
- 若發現不一致，建議排查：
  1. 客戶端是否升級並重新啟動。
  2. API Key 是否被錯誤共用或遭到竄改。

## 建議的排查步驟
1. 檢查客戶端啟動參數，確認 `User-Agent` 是否帶上預期版本號。
2. 在管理端重刷 API Key 列表，確認最新版本是否同步。
3. 若仍被攔截，可暫時禁用統一版本校驗以便定位，完成升級後再重新開啟。
